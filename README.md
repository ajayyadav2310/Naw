# MoneyTrack

Offline-first personal finance tracker for Android (Capacitor + Vite). Dark-only UI, INR (₹), no login, no cloud.

## Features

- Accounts: **India Post Payments Bank**, **Central Bank of India**, **Other Bank** (you can add more, set opening balances)
- Manual **income**, **expense** and **account-to-account transfers** (transfers are excluded from income/expense totals)
- Transaction history with search (person, category, account, amount, notes), month/type filters, edit and delete
- Custom **categories**, **monthly report** (income, spend, net, by category, by account)
- **CSV export** and **JSON backup / restore** (restore is validated; older v1 backups still load)
- **Automatic tracking** (Android only, with your permission):
  - *Notifications*: `NotificationListenerService`, enabled by you in Android's Notification Access settings
  - *SMS*: `RECEIVE_SMS` broadcast receiver for live capture + on-demand import of recent inbox (`READ_SMS`)
  - Both run natively, so they keep capturing while the app UI is closed. Detected items wait in a durable queue and are
    saved into the app (and acknowledged) the next time it opens or is in the foreground
  - OTP / failed / "will be debited" / payment-request messages are ignored; balance figures are not mistaken for the amount
  - Imported entries are marked **Review** until you open and save them; deleting one stops it being re-imported
  - Duplicates are detected (same UTR/reference, same text, same payment seen as SMS *and* notification)
- Everything is stored on the device (Capacitor Preferences). No bank APIs, no fake data, no OTP/PIN/password handling.

## Project layout

| Path | Purpose |
|---|---|
| `www/` | Web app: `index.html`, `style.css`, `app.js` (UI), `lib.js` (pure logic) |
| `android-native/…/*.java` | Native Android code copied into the generated project at build time |
| `scripts/patch-android.py` | Adds native code, permissions, receiver/service and dark theme to the generated `android/` project (idempotent, fails loudly) |
| `scripts/test-java.sh`, `tests/` | Parser unit tests (Java) and logic tests (Node) |
| `.github/workflows/android-debug.yml` | CI: test → build web → generate Android project → patch → Gradle → verify APK → upload |
| `database/schema.sql` | Reference only (not used at runtime) |

`android/` is generated by CI (`npx cap add android`) and is git-ignored, so the repository stays small and always matches the Capacitor version in `package.json`.

## Build locally (needs JDK 21, Node 20+, Android SDK 35)

```bash
npm install
npm test && npm run test:java
npm run build
npx cap add android
python3 scripts/patch-android.py
npx cap sync android
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

## First run on the phone

1. **Settings → Automatic tracking → 1. Enable notification access** → switch MoneyTrack on.
2. **2. Allow SMS permission** (needed for live SMS capture and import).
3. **3. Allow background activity** → choose *Unrestricted / Don't optimise*.
4. Android 13+ and apps installed from a file: if the switches are greyed out or the SMS prompt never appears, open
   **Settings → Open app info → ⋮ → Allow restricted settings**, then repeat steps 1–2.
5. Some phones (Xiaomi, Oppo, Vivo, Realme, Samsung) also have *Autostart / Battery saver* lists - allow MoneyTrack there.

## Limitations (please read)

- **Parsing is heuristic.** Bank message formats vary; some messages will be missed or mis-categorised. Always review entries marked *Review*.
- **Account matching is by bank name in the message/sender** (IPPB, Central Bank/CBoI); everything else goes to *Other Bank*. Several accounts at one bank cannot be told apart.
- **Imports reach the app when it is next opened** (detection itself is native and continues in the background). Android may stop background components on aggressive battery managers - see step 5 above.
- **Notification Access** is a special Android setting; it cannot be granted by a pop-up. SMS permission is a normal runtime permission.
- **Google Play** restricts SMS/notification access; this build is for personal sideloading, not Play Store distribution.
- **Debug APK**, signed with a debug key that CI regenerates every run, so a new build cannot be installed over an older one - uninstall first (back up with JSON export, then restore). Auto-backup is disabled (financial data), so uninstalling deletes data: **export a JSON backup regularly**.
- Balances are *recorded* balances (opening balance + your transactions), not verified live bank balances.
- Data is stored as a validated JSON document, not SQLite (`database/schema.sql` is a future option).
- The template's `INTERNET` permission remains but the app makes no network requests.
- No `package-lock.json` is included (it could not be generated offline); CI uses `npm install` with `^7` Capacitor ranges.
